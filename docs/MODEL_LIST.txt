REGRAS
  - Nome do arquivo = ID do item. Ex.: AK47.fbx, Optic_RedDot.fbx
  - Cada item tem sua pasta em Contents/mods/ZEGunsOfBohemiaCore/42/media/models_X/ZGB/
    (hoje tem um placeholder lá: troque pelo seu modelo com o mesmo nome).
  - Unidade: metros. Eixos: x = para frente (boca do cano), y = para cima, z = para a direita.
  - Origem da arma: topo do punho, onde a mão segura.
  - Origem do attachment: o ponto onde ele encaixa. Supressores/freios crescem para
    frente, coronhas para trás, miras para cima, empunhaduras/lanternas para baixo.
  - Tamanhos abaixo: arma = comprimento real; attachment = tamanho do placeholder
    (comprimento x altura x largura), só como referência.
  - Variantes (ex.: AK47__Mount_AK_SideRail) NÃO entram nesta lista: modele a arma
    base e cada peça separada. As variantes são a arma com a peça já montada.
  - Guia completo: docs/MODELS.md
